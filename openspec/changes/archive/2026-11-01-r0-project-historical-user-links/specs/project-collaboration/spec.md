# Spec Delta

## MODIFIED Requirements

### Requirement: 项目成员可读取用户明确提供的网页来源
系统 SHALL 允许项目成员直接读取项目原始委托、当前项目群用户消息或同一项目群中有限数量的近期已完成用户消息明确提供的公开 URL，无需配置网页搜索服务。读取只允许访问这些精确 URL，并 SHALL 将成功读取的来源链接附到公开成果；失败页面不得作为已读取来源。

#### Scenario: 没有搜索服务时读取用户给出的官方页面
- **WHEN** 项目用户当前消息明确包含公开页面 URL，且成员被要求核查该来源
- **THEN** 成员可以直接读取该 URL，无需 Tavily 密钥
- **AND** 成功读取的正文、标题和链接可用于本轮结论，链接随公开成果记录
- **AND** 每个项目成员回合最多读取三项来源

#### Scenario: 没有搜索服务时读取用户先前在群中给出的官方页面
- **WHEN** 项目用户此前在同一项目群中发送了公开页面 URL，且成员被要求核查该来源
- **THEN** 成员可以直接读取该 URL，无需 Tavily 密钥
- **AND** 成功读取的正文、标题和链接可用于本轮结论，链接随公开成果记录
- **AND** 每个项目成员回合最多读取三项来源

#### Scenario: 成员尝试读取用户未提供的 URL
- **WHEN** 成员请求读取的 URL 不在项目原始用户委托、当前项目群用户消息或同一群聊近期已完成用户消息的明确链接列表中
- **THEN** 系统拒绝网络请求，并说明该 URL 未获本项目用户消息授权

#### Scenario: agent 消息包含网页链接
- **WHEN** agent 在项目群中发送 URL，且该 URL 未由用户在授权范围内明确提供
- **THEN** 系统不得将该 URL 视作用户授权来源或发起网络请求

#### Scenario: 用户粘贴的链接紧邻中文标点
- **WHEN** 用户消息中的公开 URL 后紧跟中文右括号、逗号或句号
- **THEN** 系统读取规范化后的 URL，不将标点并入请求地址

#### Scenario: 用户提供的网页无法读取
- **WHEN** 用户给出的链接无法访问、重定向越界或正文类型不受支持
- **THEN** 系统返回明确的读取失败结果，不将其记为已读取来源或核验依据

#### Scenario: 网页正文包含指令或超出读取边界
- **WHEN** 已读取页面包含提示词、脚本或过长内容
- **THEN** 页面内容只作为不可信资料返回；系统沿用网页读取器的网络地址、响应大小和正文长度限制
