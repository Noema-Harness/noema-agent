## Why
OpenSpec 变更流程、DLM 资料生命周期和 GitHub 交付尚未在用户级形成统一维护入口；将资料维护挂在 OpenSpec 下会误导普通维护也必须先进入规格流程。
## What Changes
建立一个用户级 development-maintenance 技能，承接恢复、资料有效性与 GitHub 交付，迁移 DLM 的唯一维护位置；精简全局与项目入口，保留 OpenSpec 本职。不重建已封存的看板。
## Capabilities
### New Capabilities
无产品行为新增，属于用户级开发工作流维护。
### Modified Capabilities
无。
## Impact
用户级 AGENTS、skills 及 Noema 项目工作约定；不修改业务源码、用户数据或运行权限。
