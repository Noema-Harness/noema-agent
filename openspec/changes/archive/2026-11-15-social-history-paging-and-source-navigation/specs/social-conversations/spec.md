# Spec Delta

## ADDED Requirements

### Requirement: Renderer 可在有界窗口中浏览聊天历史并定位来源

Renderer 读取聊天房间时，系统 MUST 返回有界的最新消息窗口及是否存在更早记录的游标元数据。每次返回的消息数 MUST 不超过 200 条。用户请求更早记录时，系统 MUST 以稳定消息序号分页；页面接入较早记录时 MUST 保持原阅读锚点。搜索或历史回忆跳转 MUST 直接读取目标消息附近的窗口，不得先读取整个房间历史。

#### Scenario: 打开有大量历史的房间

- **WHEN** 用户打开包含超过 200 条记录的聊天空间
- **THEN** 系统只返回最近最多 200 条消息，并明确提供可继续读取更早消息的状态

#### Scenario: 加载更早的消息

- **WHEN** 用户请求早于当前窗口的历史
- **THEN** 系统按序号返回不超过 200 条消息，前端保留已显示内容并维持用户原阅读位置

#### Scenario: 定位较早的搜索结果或回忆来源

- **WHEN** 用户从搜索结果或回忆来源跳转到当前窗口以外的一条消息
- **THEN** 系统围绕该消息读取有限窗口并将目标滚动到视野中

#### Scenario: 搜索较早的当前房间消息

- **WHEN** 用户在当前聊天中查找一条位于最新 200 条消息之前的消息
- **THEN** 系统在 main 侧从该房间完整历史中找到该消息，最多返回 50 条结果，并在用户选择后定位到消息附近的有限窗口

#### Scenario: 当前聊天搜索失败

- **WHEN** main 侧搜索失败
- **THEN** 系统显示错误原因并提供重试操作，保留搜索词且不将错误显示为空结果

#### Scenario: 来源已移除或不可达

- **WHEN** 用户打开的搜索来源消息或房间在读取前已删除/移除
- **THEN** 系统展示该来源当前不可用的明确反馈，保持当前聊天状态，不静默丢弃导航操作

#### Scenario: 分页参数无效或读取失败

- **WHEN** 房间游标参数无效，或分页查询遇到存储错误
- **THEN** 系统拒绝无效输入或显示可重试错误，不扩大读取为全量历史，也不丢弃已显示的消息

### Requirement: 当前聊天搜索覆盖完整历史并明确反馈状态

当前聊天搜索 MUST 由 main 侧按明确的房间 ID 检索该房间完整历史，最多返回 50 条，并与其它房间隔离。搜索界面 MUST 分别呈现加载、无结果和错误状态，错误后允许用户重试。

#### Scenario: 搜索较早的当前房间消息

- **WHEN** 用户在当前聊天中查找一条位于最新 200 条消息之前的消息
- **THEN** 系统在 main 侧从该房间完整历史中找到该消息，最多返回 50 条结果，并在用户选择后定位到消息附近的有限窗口

#### Scenario: 当前聊天搜索失败

- **WHEN** main 侧搜索失败
- **THEN** 系统显示错误原因并提供重试操作，保留搜索词且不将错误显示为空结果
