## Context
OpenSpec 已部署，原有 PLANS.md 和项目管理技能仍在独立规定计划；六个官方技能与中文适配入口并列，部分上游技能要求规划结束即停下。
## Goals / Non-Goals
减少入口与重复状态，保留项目特有工程边界、成熟工具和实际验证；不改变 Noema 业务实现或正在进行的产品工作。
## Decisions
用户级 AGENTS 只保留协作责任和工程依据；OpenSpec CLI 与单一全局入口负责变更过程。官方生成文件留在本机参考源，由官方 update 刷新，删除六份全局副本及复制同步脚本。GitHub 管交付状态，change 管细任务和证据；ADR 只记录长期取舍，避免重复 design。项目管理技能专注 GitHub 与发布，细分技术说明按需加载。
## Risks / Trade-offs
入口缩减不证明行为已经改善；通过真实 CLI 续接、技能元数据检查和后续工程结果检验。删改前保留本机备份，项目旧版由 Git 恢复。
