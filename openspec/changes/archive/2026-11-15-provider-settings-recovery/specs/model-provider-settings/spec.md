# Spec Delta

## Purpose

为用户管理对话模型连接、选择可用模型并安全恢复配置问题提供可观察的设置行为。

## ADDED Requirements

### Requirement: 用户可以安全地重新检查已配置的模型服务

设置 MUST 允许用户使用已保存凭据主动重新检查模型服务并刷新可用模型状态。保存的凭据 MUST NOT 回填、回显或提供给 renderer；重新检查 MUST 不要求用户再次输入凭据。

#### Scenario: 重新检查已配置连接
- **WHEN** 用户在已配置的模型服务设置中选择“重新检查”
- **THEN** 设置显示检查进行中状态，并在完成后显示最新连接状态和可用模型列表

#### Scenario: 检查失败时保护凭据
- **WHEN** 已配置服务的连接检查失败
- **THEN** 设置显示可理解的错误与下一步操作，且 renderer 中不存在已保存的凭据值

### Requirement: 模型配置失败后保留恢复路径

设置 MUST 将保存或连接检查结果显示在模型设置中。连接失败时 MUST 保留设置窗口及可用的重试或更改配置操作；凭据替换字段 MUST 保持为空白且使用密码输入类型。

#### Scenario: 新配置连接失败
- **WHEN** 用户提交服务地址和密钥，但服务不可达或未返回可用模型
- **THEN** 设置保留窗口，说明连接失败并允许重新检查或更改配置

#### Scenario: 替换密钥
- **WHEN** 用户选择更改现有模型服务配置
- **THEN** 密钥输入为空白且为密码类型，只有用户输入的新值才可提交
