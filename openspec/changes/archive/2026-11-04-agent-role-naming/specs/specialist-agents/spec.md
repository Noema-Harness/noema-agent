# Spec Delta

## MODIFIED Requirements

### Requirement: 专业成员拥有稳定身份和常驻私聊
系统 SHALL 为用户创建的专业成员保留稳定身份及独立常驻私聊；创建成员不得导入其他聊天空间的消息。模型为用户创建专业成员时，成员名称 MUST 简洁体现其持续职责或专业定位，不得自行编造仿真人类姓名或身份；只有用户明确要求使用人名或指定人设时才可使用。用户手动输入或修改的名称 SHALL 原样保留。

#### Scenario: 创建专业成员
- **WHEN** 用户创建一位专业成员
- **THEN** 成员出现在联系人列表并拥有独立的常驻私聊，初始消息不含其他聊天的历史

#### Scenario: 模型按职责命名新成员
- **WHEN** Noema 为明确委托创建专业成员，且用户没有要求人名或人设
- **THEN** 成员名称直接说明其持续职责或专业定位，且不模拟真实人名或个人身份

#### Scenario: 用户明确要求人名或人设
- **WHEN** 用户明确要求给新成员使用某个人名或人设名称
- **THEN** Noema 可以按该明确要求命名该成员
