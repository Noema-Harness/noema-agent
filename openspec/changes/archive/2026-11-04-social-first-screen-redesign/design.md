# Design

## Context

见 proposal.md。已通过 Electron `webContents.capturePage()` 截取未修改源码的实际首次启动画面；基线保存在 `.work/scratch/noema-before.png`。截图显示应用分栏和输入区已占满窗口，空聊内容靠近输入区下缘；本轮不再猜测外层高度问题。

## Goals / Non-Goals

**Goals:**

- 用用户可立即执行的操作替代无用引介，减少主聊空白，同时不伪造近期活动或能力状态。
- 将现有的连接状态、创建成员/项目、个人记忆、回访和搜索能力放在用户预期的位置，并保留现有业务逻辑。
- 使用已有 app 色彩与控件体系重新调整对比、间距、圆角和输入反馈；避免新加依赖和无功能装饰。
- 对首屏、设置对话框、已归档入口与窄窗口产物执行 Electron 原生截图复核。

**Non-Goals:**

- 不改模型服务协议、聊天存储、首次相遇持久状态和 agent 提示词。
- 不添加账户资料页、仪表盘、活动统计、模板提示词或新用户教育流程。
- 不重构项目工作区、聊天消息和执行状态的业务组件。

## Decisions

1. **主聊空状态使用一块对齐输入区的简洁内容区。** 不做居中的大 hero 或建议 prompt 卡片。依据截图，现有内容虽靠下但缺少行动；将它改为短标题、基于连接状态的说明和 1–2 个真动作，内容宽度对齐 composer。输入框仍是主要工作入口。

2. **状态提示使用内联行。** 在主聊为空时，中心内容承担连接引导，composer 上方不重复显示状态条；已有消息时才显示一行状态圆点、短说明和连接操作。删除目前的左侧色条，不再让 warning 看起来像引用块。

3. **导航入口就地显式。** 成员、项目计数标题提供加号，个人分组放入现成的记忆、回访与设置入口。设置入口改名“设置”。相较把所有动作塞进一个设置弹窗，这种做法缩短到功能的路径并维持已有功能实现。

4. **搜索作用域以文字区分。** 保留全局搜索图标和成员/项目筛选框的搜索图标；当前聊天查找改成“聊天内查找”文字控件。快捷键与搜索实现不变，避免同一屏三个相同图形。

5. **保留 Noema 已有材料并修整层级。** 沿用暖白、墨色、陶红和松绿作为统一表面色；sidebar、顶栏、composer 通过明度与细边界分层。 hover、pressed、focus-visible 和 disabled 状态共享稳定尺寸，不新增品牌图像或视觉噪声。

6. **验证使用应用自身截图。** 新增的 opt-in smoke hook 仅当指定 `NOEMA_SMOKE_SOCIAL_START_STATE_PATH` 时保存一次 main-window `capturePage()`；运行于隔离的 smoke userData，截图前只等待两帧绘制。用户当前已打开窗口和真实数据不参与。

## Risks / Trade-offs

- [空状态动作与侧栏快捷入口重叠] → 主聊只提供连接/开始聊天/新建项目，侧栏负责成员和个人管理，不重复放项目提示卡。
- [连接检查正在进行时状态仍会短暂变化] → 文案区分检查中、未配置和不可用，操作始终打开设置。
- [截图 smoke 的临时首次启动状态不含用户模型凭据] → 用于核对布局与文案，真实连接及用户数据状态仍按实际代码条件渲染，不以 smoke 证明模型运行。

## Migration Plan

无数据迁移。旧首次相遇记录保留供既有存储与 prompt 上下文兼容；renderer 不再显示或重新播放创作者说明。回退本变更可恢复旧组件。
