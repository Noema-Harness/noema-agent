# Spec Delta

## ADDED Requirements

### Requirement: 空主聊按连接状态提供下一步
当 Noema 主聊没有用户或助手消息时，界面 MUST 根据模型连接状态说明当前能做什么，并提供与该状态相符的直接操作；不得以创作者宣言或虚构活动填充空白。

#### Scenario: 模型尚未就绪
- **WHEN** 用户打开空主聊且没有可用模型
- **THEN** 界面解释需要连接模型，并可直接打开连接设置

#### Scenario: 模型可用
- **WHEN** 用户打开空主聊且模型可用
- **THEN** 界面可直接聚焦消息输入区或创建项目

### Requirement: 个人和空分类导航可用
侧栏中的空成员与项目分类 MUST 提供对应的创建操作；个人区 MUST 提供可操作且名称准确的个人功能入口。

#### Scenario: 打开个人功能
- **WHEN** 用户在个人区选择个人记忆、回访提醒或设置
- **THEN** 系统打开所选的管理界面

#### Scenario: 从空分类创建
- **WHEN** 用户查看空成员或空项目分类
- **THEN** 用户可直接打开对应的新建操作

### Requirement: 搜索入口说明范围
各搜索与筛选入口 MUST 让用户能够辨认它们的作用范围。

#### Scenario: 查找消息或空间
- **WHEN** 用户查看全局搜索、侧栏筛选和当前聊天查找入口
- **THEN** 全局入口表示跨空间查找，侧栏入口表示成员或项目筛选，当前聊天入口明确表示只搜索本聊天
