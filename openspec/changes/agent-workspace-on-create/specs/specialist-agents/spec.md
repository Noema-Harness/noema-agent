## ADDED Requirements

### Requirement: 新建成员即准备默认工作目录

系统 SHALL 在用户新建专业成员时为其准备默认工作目录；目录创建失败 MUST NOT 阻断成员创建，后续发起任务时再补建。

#### Scenario: 新建成员后工作目录存在

- **WHEN** 用户新建一位专业成员
- **THEN** 该成员的默认工作目录随即创建，目录名包含成员名称与身份标识

#### Scenario: 工作目录创建失败

- **WHEN** 新建成员时默认工作目录无法创建
- **THEN** 成员仍正常出现在联系人列表，首次发起任务时再尝试创建目录
