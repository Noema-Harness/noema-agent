# Proposal

## Why

项目执行 agent 有工具调用预算，但当前预算边界可能以普通失败结束；真实项目记录中已经出现过工具轮数上限失败。长任务需要在有限成本与连续推进之间有明确交接：达到预算时保存已完成操作，说明剩余工作，并让 Noema 或用户能决定是否续接。

## What Changes

- 达到单次执行工具预算时，不再尝试执行超预算工具，也不把预算耗尽伪装成完整交付。
- 在安全模型边界生成明确的进度交接，列出已做、未做及建议续接点；保留现有检查点与恢复路径。
- 将预算边界与上下文溢出、工具执行错误等真正失败分开呈现。

## Capabilities

### New Capabilities
- `project-execution`: 项目执行预算、部分进度交接与安全续接。

### Modified Capabilities

## Impact

- 影响项目执行器、任务状态与恢复判定、用户可见执行卡片及相关验证。
- 不增加模型提供商、外部服务或执行权限；沿用现有工具调用上限和检查点。
