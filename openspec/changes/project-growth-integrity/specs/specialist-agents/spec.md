# Spec Delta

## ADDED Requirements

### Requirement: 项目结束后的成员复盘只沉淀有证据的经历

项目归档前的成员复盘回合 SHALL 只在真正写入资产版本时保存经历简述。保存的简述 MUST 去掉工具调用痕迹并限制长度。复盘回合没有写入资产版本时 MUST NOT 保存简述，也 MUST NOT 把该回合正文当作经历注入成员的常驻私聊。复盘回合里模型把工具调用写成文本、或输出被截断时，该回合 SHALL 记为可重试失败，不得记成"无变更"。

#### Scenario: 复盘写入了一条经历

- **WHEN** 成员复盘回合调用 `manage_member_assets` 写入经历并成功
- **THEN** 该成员记录为"已完成"，简述去掉工具调用痕迹并限长，常驻私聊下一次对话可以读到它

#### Scenario: 复盘没有产生资产变更

- **WHEN** 成员复盘回合结束但没有产生任何资产版本
- **THEN** 该成员记录为"无变更"，不保存简述，常驻私聊不会再收到该回合的正文

#### Scenario: 模型把工具调用写成了文本

- **WHEN** 复盘回合的回复正文里出现工具调用标记，但没有可解析的工具调用
- **THEN** 该回合记为可重试失败，不写入经历，也不记为"无变更"

#### Scenario: 复盘输出被截断

- **WHEN** 模型输出因为长度限制被截断，且没有完整工具调用
- **THEN** 该回合记为可重试失败，不保存不完整的正文
