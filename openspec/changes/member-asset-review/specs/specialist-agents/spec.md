# Spec Delta

## ADDED Requirements

### Requirement: 成员经历由用户核对与撤回

系统 SHALL 让用户在不依赖模型的情况下查看专业成员沉淀的经历：列表显示路径、修订号、写入依据、来源项目与时间，并可读取当前内容。用户 SHALL 能删除当前经历并从历史版本恢复；删除与恢复 MUST 以追加版本（墓碑）记录依据，不得物理删除历史。归档成员的经历 MUST 仍可查看，但 MUST NOT 允许删除或恢复。

#### Scenario: 查看成员经历

- **WHEN** 用户在某专业成员上打开经历列表
- **THEN** 系统列出该成员当前未删除的经历，含路径、修订号、写入依据、来源项目与时间；没有经历时给出空态说明

#### Scenario: 删除一条经历

- **WHEN** 用户对当前经历确认删除
- **THEN** 该经历从当前列表消失，版本表追加一条墓碑记录与删除依据，历史里仍能看到它

#### Scenario: 从历史恢复经历

- **WHEN** 用户对一个未删除的历史版本选择恢复
- **THEN** 该内容成为当前经历，修订号递增，提示恢复到哪个修订

#### Scenario: 归档成员的经历只读

- **WHEN** 成员已归档且用户打开经历列表
- **THEN** 经历内容仍可查看，删除与恢复不可用并说明原因
