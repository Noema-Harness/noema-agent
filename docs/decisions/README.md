# 历史决策记录

本目录有两个当前维护入口：本说明负责 ADR 的使用与重审方式，`TEMPLATE.md` 负责新增 ADR 的结构；编号文件是只读历史，默认不在恢复上下文时逐篇读取。历史状态、实现描述和模型配置可能已被后续变化取代；当前产品、代码与行为依据以 `docs/PRODUCT_CHARTER.md`、`docs/ARCHITECTURE.md`、相关 OpenSpec 和源码为准。

需要解释某项决定时按关键词查找相应 ADR，并核对后续决定、当前文档和代码。新 ADR 仅用于跨多个变更仍须成立的产品或架构取舍；当前 change 的技术设计、实施与验证留在 OpenSpec。若旧决定不再适用，新增明确的替代决策并链接旧 ADR，不重写历史来伪造一致性。新增 ADR 后同步更新本索引（编号、标题、状态、取代关系）；不维护重复的完整清单。
