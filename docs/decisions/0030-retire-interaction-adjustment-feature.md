# ADR 0030：把交流方式留在普通对话中

- 状态：接受；取代 ADR 0024 在当前产品路径中的互动约定功能
- 日期：2026-10-23
- 决策者：用户
- 依据：用户指出，智能体理解当前请求、遵循用户在对话中的明确要求，是 agent 应用的基础行为；将其另建为可管理约定、每轮附加快照和逐条展示的专门功能，增加了用户概念负担、提示词和持久状态复杂度，却没有证明独立价值。

## 决定

1. Noema 当前聊天及项目任务不再自动读取、注入或展示“互动约定”。本轮明确指示直接进入当前消息上下文，不需要再复制成另一种持久对象。
2. 不在新主界面中提供约定的创建、编辑、撤回或逐轮追踪入口，也不增加替代名称来保留同一套机制。
3. 已有本机数据库记录和历史消息/任务快照暂时保留，但不再参与新请求。这个兼容状态不构成继续开发该功能的理由。
4. 只有真实使用证据再次显示普通对话无法承接重复、明确的用户要求时，才重开设计；届时先比较简单的系统提示、用户设置或现有记忆能力，不预设恢复独立约定子系统。

## 后果

当前聊天和文件任务少一层自动上下文，历史页面也不再宣称每轮应用了某个特殊机制。旧 schema 与历史内容尚未清理，后续如需删列或删除旧记录，应在确认旧版本兼容范围后单独迁移；当前工作不改写或丢弃用户数据。
