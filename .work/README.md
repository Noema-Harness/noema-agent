# 工作材料入口

这里保存过程材料和只读历史，不是当前产品规格或任务来源。

- `runs/`：脚本自动生成的隔离运行、截图和日志，可通过 workspace:clean 预览清理。
- `scratch/`：随时可再生的草稿，可通过同一命令清理。
- `<主题>/`：进行中的研究、下载和整理材料，由对应 change 引用。
- `source-refactor/`：源码结构迁移与客户端收尾记录；社交主流程 E2E 已通过（成功运行会自动清理隔离数据与截图）。其余启动日志作为只读历史保留。
- `archive/`：保留的旧材料，按需追溯，默认清理不触及。

旧看板本地预览：`archive/2026-10-31/github/index.html`（仅保留在归档所在的本机）。快照和旧设计材料不再更新，不能推断当前实现。用户数据库、凭据不得作为可随时清理的草稿。
