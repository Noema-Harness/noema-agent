# 工作材料

只保存当前仍有用途的材料。

- `references/README.md`：六个主体固定提交及 Windows 隔离专项源码参考；不是已采用方案，研究中可按证据取舍或补充。
- `planning/PLANNING_CONTRACT.md`：一期规划研究与设计契约；恢复规划工作时先读。
- `planning/PROGRESS.md`：规划阶段完成状态和审计记录，供上下文恢复与后续衔接。
- [../docs/NOEMA_V1_PLAN.md](../docs/NOEMA_V1_PLAN.md)：Noema 一期唯一权威阶段计划，含范围、阶段依赖和逐项验收。
- `planning/research/`：按参考仓库和领域形成的可追溯研究卡片与模块图谱。
- `runs/`：新产生的隔离运行与日志，按用途清理。
- `scratch/`：可再生临时脚本和文件。

旧规划、历史说明、运行快照和被替代研究已从工作区移除。保留的过程材料不能自动成为产品要求。用户数据、凭据、依赖和必要测试 fixture 不作为过程文件清理。
