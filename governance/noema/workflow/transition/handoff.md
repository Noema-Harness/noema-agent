# 执行交接

执行 → 验收的入口。执行者与验收者不是同一个角色；没有这份数据，验收只能逐条询问或只看结果。

## 触发

切片全部完成，或明确阻塞且剩余部分已写清。

## 结构

```
# 执行交接：<批次名>
- 条目：<D-…>；批次：changes/<name>；commit：<sha>

## 交付物
文件 / 命令 / commit（一行一个指针）

## 证据索引
测试输出、CI run、截图、演练记录

## 未验证项
每条写为什么没验、如何验（没有就写「无」，不省略）

## 已知风险

## 验收步骤（≤15 分钟）
1. <操作> → 期望结果
2. …

## 回退方式
```

## 生成方式

骨架从 change 的 tasks、条目执行层、最近测试输出自动生成（批次二：`npm run handoff`）；agent 只补「未验证项 / 风险 / 验收步骤」三节。

## 判据

用户照步骤独立跑完；每步都有期望结果；未验证项显式说明。
