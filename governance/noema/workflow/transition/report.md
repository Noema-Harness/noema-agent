# 验收报告

验收 → 收口的记录。从验收页导出，不写新叙述；证据已在 change 与验收页，这里只做索引。

## 触发

用户勾完验收项并给出确认原话。

## 结构

```
# 验收报告：<批次名>
- 条目：<D-…>；批次：changes/<name>；commit：<sha>

| 验收项 | 标记（用户 / 机制 / 未验证） | 结果 | 证据 |
|---|---|---|---|
| … | [用户] | 通过 / 不通过 | commit / run / 截图 |

- 用户确认：原话 + 日期
- 遗留项：进卡片 / 下一条目 / 明确不做
- 结论：收口 / 决定变了回决策中 / 实现偏差回执行中修
```

## 生成方式

从验收页导出（批次二：`npm run acceptance-report -- <id>`）。

## 判据

每勾选项有证据指针；确认原话与日期存在；遗留项有去处；结论明确。
