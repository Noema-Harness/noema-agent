# 讨论

只在有交付物、但还不清楚要交付什么的时候进这个状态。聊天、查资料、临时提问不进会话。

## 做什么

- 把问题对齐成一句范围：`npm run state -- scope "这一轮要交付什么" [--kind 里程碑|修复]`。
- 记下这一轮的结论与它改变了什么：`npm run state -- round "结论" --change "改了什么"`。
- 拿不准的先摆着：`npm run state -- wait add "…"`，定了用 `wait drop "…"` 划掉。
- 连续几轮没有新证据，就收口：写范围，再 `npm run state -- set 执行 --reason "结论已定"`。

## 检查

- [ ] gate:source-boundary 结论落到仓库文件，不只在对话里。
- [ ] gate:status-today 如果这次讨论改变了能用到哪，`docs/STATUS.md` 要改。

## 不要做

- 不在讨论态写产品代码；此时没有范围，提交门会拒绝产品行为改动。
- 不把「还没有补充」当成开工许可。
- 不替用户决定范围里包含什么、验收怎么算通过。
